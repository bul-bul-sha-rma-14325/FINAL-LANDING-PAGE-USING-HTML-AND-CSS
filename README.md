PRACTICE PROJECT 
This project is a fully responsive **Tech Landing Page** created using **HTML and CSS**.  
It includes components such as navigation bars, hero sections, feature cards, product sections,Contact section, buttons, and layouts typically used in modern tech websites.

Features:
Clean and modern UI
Fully responsive
Pure HTML & CSS
Easy to customize

What you will learn:
 🌐 HTML Skills
- Structuring a webpage using semantic HTML
- Adding images, headings, text, and labels
- Using anchor tags for links and social icons
- Building sections like headers, content areas, and buttons
- Organizing project files and linking CSS files

  🎨 CSS Skills
- Styling elements using classes and IDs
- Applying colors, fonts, spacing, and alignment
- Using CSS Flexbox / Grid for layout design
- Creating responsive and clean UI layouts
- Implementing hover effects and transitions
- Designing modern UI components like cards and buttons
- Adding shadows, borders, and rounded corners
- Working with background colors and custom themes


How to Use:

1.Download or clone the repository
2.Open index.html in any browser
3.Customize the content as needed
